# EarthMC Market v0.5.50 — Coordinate-based head favorites

- `/emprice favhead` now supports player heads placed directly on walls or floors, as well as framed heads.
- When no reliable skin fingerprint is present, wishlist keys use dimension and exact block coordinates rather than an ambiguous item name. Different same-named heads can be favorited separately.
- Heads GUI favorite toggles and Favorites-only filtering use the same key as the command.
- Existing head catalogue, manual names and previous wishlist entries are preserved.
- Position-based favorites refer to the specific display location; if the owner replaces that head, the saved location should be reviewed and re-favorited if appropriate.
- Source archive only; full Minecraft/Fabric Gradle compile and in-game testing are not performed here.
